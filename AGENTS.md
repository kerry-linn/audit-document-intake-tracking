# Repository workflow

These instructions apply to all work in this repository, including documentation changes.

- Create a separate branch from the latest `main` for each task before making changes.
- Commit and push changes to the task branch, then open a pull request targeting `main`.
- Never commit or push directly to `main`.
- Leave pull requests open for human review. Do not merge a pull request or enable auto-merge unless the user explicitly approves merging that pull request.
- Run checks appropriate to the change and describe the changes and validation in the pull request.
- Include the pull request link in the final response.
