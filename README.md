# Audit Document Intake and Tracking

This CI 491 project explores a simpler way for auditors to track documents requested through an Open Items List (OIL). Evidence often arrives across different channels with unclear file names, making it hard to see what has been received and what is still missing.

The proposed application would let an auditor import an OIL, upload evidence, review suggested document types and request matches, and confirm or correct those suggestions before the tracker updates. The auditor remains responsible for deciding whether a request has enough evidence.

The first version is still being scoped with the stakeholder. The team is validating supported file types, tracking rules, and the overall approach before choosing an architecture or implementation stack.
